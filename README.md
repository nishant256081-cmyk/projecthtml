#SAITM Modern Page – README
This project is a modern, responsive webpage layout built using HTML5 and CSS3. It focuses on a sleek UI design with a gradient background, smooth scrolling, and a stylish navigation bar.

#🎯 Features

🌈 Gradient background for a modern look

📱 Responsive design using viewport settings

🧭 Sticky navigation bar with blur effect

✨ Smooth scrolling behavior

🎨 Clean UI with reset styling and custom font

#Key Points:

position: sticky → Navbar stays at the top while scrolling

backdrop-filter: blur(10px) → Creates a glassmorphism effect

flexbox → Aligns items horizontally

z-index: 1000 → Keeps navbar above other elements

#🚀 How to Use

Copy the code into an .html file

Open it in any browser

Add content (sections, links, etc.) below the navbar

🔧 Suggestions for Improvement

Add Google Fonts import for Poppins

Include navigation links inside .navbar

Add sections for scrolling (e.g., Home, About, Contact)

Make mobile menu (hamburger menu)

#📚 Technologies Used

HTML5

CSS3 (Flexbox, gradients, backdrop filters)
